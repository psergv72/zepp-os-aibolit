# Адаптивная раскладка экранов под форму дисплея (круглая / прямоугольная)

Дата: 2026-08-02
Ветка: `feat/adaptive-screen-layout`

## Цель

Сделать две версии раскладки страниц приложения на часах — для круглого и
прямоугольного (квадратного) экрана — с автоматическим переключением по форме
экрана устройства. Круглая версия не должна обрезаться корпусом и должна быть
удобной в использовании.

## Контекст и текущее состояние

Приложение использует императивную отрисовку виджетов (`createWidget`) без
учёта формы экрана. Все координаты захардкожены под квадрат 480×480:

- `page/home/index.js`, `page/plan/index.js`, `page/snooze/index.js`;
- `app.json`: только платформа `{ "st": "r" }`, `designWidth: 480`;
- шрифты и размеры масштабируются через `sysText()` / `getUiScale()` из
  `src/utils/ui-scale.js`.

Проблемы на круглом экране:

- чекбоксы/контролы справа (x≈430) у верхних и нижних строк выходят за
  окружность и обрезаются;
- нижние кнопки на всю ширину срезаются по краям;
- заголовок времени рисуется текстом `───── 08:00 ────` — при крупном шрифте
  (правило минимального шрифта) строки переносятся и «прокручиваются».

## Подход

Единая логика отрисовки для обеих форм с разными контентными областями.
Прямоугольная версия использует всю ширину; круглая — вписанный в окружность
квадрат (безопасную зону). Оба варианта получают одинаковые улучшения дизайна.

### Определение формы экрана

Используется `@zos/device`:

```js
import { getDeviceInfo, SCREEN_SHAPE_ROUND } from '@zos/device'
const { screenShape } = getDeviceInfo()
const round = screenShape === SCREEN_SHAPE_ROUND
```

Доступно в API 4.2 (целевая версия уже указана в `app.json`).

### Новый модуль `src/utils/screen-layout.js`

- `isRoundScreen(): boolean` — определяет форму один раз и кэширует результат.
- `getContentBounds()` — контентная область в координатах 480×480:
  - круглая: `{ left: 70, right: 410, width: 340 }` — вписанный квадрат,
    отступ `(480 − 480/√2)/2 ≈ 70`;
  - прямоугольная: `{ left: 20, right: 460, width: 440 }`.
- `renderTimeHeader(ui, { text, x, y, rowH, color, textSize, right, lineColor })` —
  рисует заголовок времени: текст слева и линию-разделитель справа.

Реализация `renderTimeHeader`:

1. измеряет ширину текста через `getTextLayout(text, { text_size })` из
   `@zos/ui` (модуль `@zos/ui` предоставляет `getTextLayout`); при недоступности
   измерения — резерв: ширина текста ≈ `text.length * text_size * 0.6`;
2. создаёт `widget.TEXT` для времени (слева, выравнивание по вертикали);
3. создаёт `widget.FILL_RECT` — линия толщиной `3 × S` от
   `x + textWidth + gap` до `right`, по вертикальному центру строки.

Линия рисуется отдельным виджетом и не зависит от ширины шрифта — не
переносится и не прокручивается.

## Изменения страниц

### Home (`page/home/index.js`)

- Заголовок «Ближайшие приёмы» — по центру контентной области.
- Блок приёма:
  - время — через `renderTimeHeader` (слева + линия до правого края контента);
  - лекарства — строки справа от колонки чекбокса;
  - чекбокс «принять» (`☐`, синий) — слева у первой строки лекарств, по
    верхнему краю блока; высота чекбокса = высоте строки (не весь блок);
    клик — принять приём.
- Кнопка «[Полный план →]» — по центру, в границах контента:
  - круглая: низ безопасного квадрата (y≈362…410);
  - прямоугольная: как сейчас (y≈380…428).
- Пустое состояние «Нет предстоящих приёмов» — по центру контента.

### Plan (`page/plan/index.js`)

Та же раскладка, что и Home, плюс состояния:

- ожидается: контроль `☐` (клик — принять, длинное нажатие — отменить), время
  белым;
- принят: время `08:00 ✓` зелёным, лекарства серым, строка «приняты в 08:05»,
  контроль `✓` (клик — отменить приём);
- отменён: зачёркивание заголовка и лекарств, строка «вернуть прием»;
- низ — «[На главную]» по центру контента.

Контрол (`☐`/`✓`) — слева у первой строки лекарств, по верхнему краю блока.

### Snooze (`page/snooze/index.js`)

- Порядок: название приёма, строка лекарств, «Отложить на:», сетка опций.
- Сетка 2×2, компактная, ближе к верху, по центру контентной области.
- Зазор между столбцами и зазор между строками одинаковый (один `g`).
- Ширина кнопок подбирается под ширину контента:
  `btnW = (contentWidth − g) / 2`; высота кнопок фиксированная.
- Формат метки кнопки — прежний: крупное число + подпись «мин».

## Платформа (`app.json`)

- `platforms`: `[ { "st": "r" }, { "st": "s" } ]`.
- `permissions`: добавить `"data:os.device.info"`.
- `app.version`: поднять до `1.1.0` (code 2).

`designWidth` остаётся `480` — квадратные устройства масштабируют координаты.

## Правила шрифтов и размеров

Без изменений относительно действующих правил AGENTS.md:

- размеры шрифтов — только через `sysText()`;
- размеры элементов/отступов — через `uiSize()`/`getUiScale()` (`S`);
- минимальный шрифт — `getSysFontSize(16)`.

    (возвращает ширину ≈ `text.length * text_size * 0.6`) и сеттер формы.
- Новые/изменённые тесты:
  - `screen-layout.test.js`: границы для круглой и прямоугольной формы;
  - home: заголовок времени создаёт виджет `FILL_RECT` (линию), а не текст с
    тире; чекбокс расположен слева и по верхнему краю (y чекбокса = y первой
    строки лекарств); на круглой форме контент в пределах безопасной зоны;

  - snooze: равные зазоры между столбцами и строками сетки.

## Вне области

- Поддержка формы «b» (полоса/браслет) — не требуется.
- Смена формы экрана «на лету» — форма фиксирована для устройства.
- Редизайн фона, иконок и палитры — не требуется.
