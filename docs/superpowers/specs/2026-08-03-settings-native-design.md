# Дизайн: нативные настройки в стиле стандартных приложений Zepp

## Проблема

Телефонная страница настроек Айболита (`src/setting/index.js`) выглядит «не по-зейповски»:
заголовки и текст уменьшены до 12–18px, списки нарисованы вручную (строки с
`borderBottom`), навигация сделана самодельными «кнопками», а элементы не сгруппированы
в секции. Стандартные приложения Zepp показывают настройки сгруппированными в нативные
секции с заголовками, стандартным размером текста и нативными элементами управления.

## Цель

Перестроить все экраны настроек на нативные компоненты фреймворка (`Section`,
`TextInput`, `Toggle`, `Select`, `Button`) с минимальными кастомными стилями, чтобы
приложение Zepp отрисовало их стандартным нативным видом.

## Объём

Меняется только `src/setting/index.js` и тесты `src/test/settings-render.test.js`.

Не трогаем: логику, хранилище, синхронизацию, часы (`src/page/*`), приложение-сервисы,
i18n-файлы.

## Общий подход

- Каждая страница собирается из `Section` + нативные компоненты.
- Убираем кастомные стили, ломающие нативность: мелкие шрифты (12–15px), строки с
  `borderBottom`, самодельные кнопки с ручным фоном.
- Остаётся минимум CSS — только отступы страницы и между секциями.
- Все метки полей и кнопок сохраняются как есть (на них опираются тесты и логика).

## Структура страниц

| Страница | Содержимое |
|---|---|
| Лекарства | Заголовок «Лекарства» → `Section("Мои лекарства")` со строками лекарств (название, дозировка, счётчик приёмов; тап → редактирование) → кнопка «+ Добавить лекарство» (`primary`) → `Section("Управление")` со строками-переходами: Приёмы, История, Настройки |
| Добавить/Редактировать лекарство | `Section("Основное")`: Название, Дозировка, Комментарии (TextInput) + Активно (Toggle) → Сохранить (`primary`), Назад |
| Приёмы | Заголовок «Приёмы» → `Section("Расписание")` со строками приёмов (метка·время, дни, состав; тап → редактирование) → «+ Добавить приём» (`primary`), Назад |
| Добавить/Редактировать приём | `Section("Время")`: Время, Метка, «Каждый день» (Toggle), Дни недели (Select) → `Section("Лекарства")`: строки препаратов (тап → правка) + «+ Добавить лекарство» → Сохранить, Удалить, Назад |
| Лекарство в приёме | `Section`: Select «Лекарство», TextInput «Количество» → Сохранить, Удалить из приёма, Назад |
| История | Заголовок «История» → `Section("Период")`: TextInput «Дата» → `Section("Записи")`: строки истории |
| Настройки | Заголовок «Настройки» → `Section("Напоминания")`: Интервал повтора, Интервал синхронизации, Варианты отложки → `Section("Отображение")`: Минимальный размер шрифта → Сохранить (`primary`), Назад |

## Стили

- `S.page`: отступы `12px 20px` — оставляем.
- Заголовок страницы: нативный размер, `bold`; жёсткий 18px не задаём.
- Строки списков: нативный размер текста (не меньше стандартного), без серого 12px.
- Кнопки: только атрибут `color` (`primary` / `default`), без ручного фона.

## Тесты

- Существующие тесты `settings-render.test.js` должны продолжать проходить: метки полей
  и кнопок не меняются, логика записи в settingsStorage и перерисовки не трогается.
- Добавляются проверки, что страницы используют `Section` с ожидаемыми заголовками
  (например, «Настройки» → Section «Напоминания» и «Отображение»).

## Проверка

- `npm test` (в каталоге `src/`) — все тесты зелёные.
- Ручная проверка в приложении Zepp: страницы выглядят нативно, элементы читаемы.

## Не входит в объём

- Логика, хранилище, синхронизация, расписания.
- Часы (`src/page/home|plan|snooze`).
- Файлы `*.po` / i18n.
