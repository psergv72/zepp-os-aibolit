Выполни следующий сценарий работы с файлом `TODO.md` (в корне проекта). Все сообщения пользователю — на русском языке.

## Шаг 1. Чтение TODO.md

Прочитай файл `C:\_Soft\_ZepOS\aibolit\TODO.md`. Найди все пункты списка (строки, начинающиеся с `- `) в разделе задач. Исключи уже выполненные пункты — те, что помечены префиксом `- [x]` или `- [X]`.

Если незавершённых пунктов нет, сообщи об этом пользователю и заверши работу. Больше ничего не делать.

## Шаг 2. Выбор пункта

Покажи пользователю список незавершённых пунктов в виде сокращённых наименований — короткой формулировки сути каждого пункта (примерно 1–5 слов), сохранив порядок следования в файле.

Дай пользователю выбрать один из пунктов через инструмент `question`. В качестве `label` для каждого варианта используй сокращённое наименование, а в `description` — полный текст пункта. Заголовок вопроса: «Какой пункт TODO выполняем?». Вопрос — одиночный выбор (`multiple: false`). Если `$ARGUMENTS` содержит номер пункта или его сокращённое наименование, используй этот пункт без запроса.

## Шаг 3. Создание git-ветки

Определи имя ветки из сокращённого наименования выбранного пункта:
- Транслитерируй кириллицу в латиницу (примеры: а→a, б→b, в→v, г→g, д→d, е→e, ё→yo, ж→zh, з→z, и→i, й→y, к→k, л→l, м→m, н→n, о→o, п→p, р→r, с→s, т→t, у→u, ф→f, х→kh, ц→ts, ч→ch, ш→sh, щ→shch, ъ→опустить, ы→y, ь→опустить, э→e, ю→yu, я→ya).
- Приведи к нижнему регистру, замени пробелы и недопустимые для имён веток символы на дефис, удали повторяющиеся дефисы.
- Собери имя: `todo-<транслитерированное имя>` (например `todo-udalenie-lekarstva`).
- Проверь через `git branch --list`, не существует ли уже ветки с таким именем. Если существует — добавь суффикс `-2`, `-3` и так далее, пока имя не станет свободным.

Создай и переключись на новую ветку от текущей через `git checkout -b <имя_ветки>`. Сообщи пользователю имя ветки.

## Шаг 4. Выполнение пункта

Выполни выбранный пункт в созданной ветке: изучи код, внеси необходимые изменения, проверь работоспособность (сборка, линтеры, тесты там, где применимо).

## Шаг 5. Перенос в TODO-COMPLETED.md

После успешного завершения работы:
1. Перенеси выполненный пункт из `TODO.md` в файл `TODO-COMPLETED.md` (в корне проекта): удали строку пункта из `TODO.md` и добавь её текст в `TODO-COMPLETED.md` в виде строки `- <текст пункта>` без префикса `- [x]`. Если файл `TODO-COMPLETED.md` ещё не существует — создай его (заголовок `# Выполнено`). Пункты в `TODO-COMPLETED.md` добавляй в конец списка, порядок не сортируй. Сортировку пунктов в `TODO.md` тоже не выполняй.
2. Закоммить изменения: сначала `TODO.md` и `TODO-COMPLETED.md`, затем остальные изменённые файлы, с осмысленным сообщением на русском. НЕ делай push без явного запроса пользователя.
3. Сообщи пользователю результат: что сделано, имя ветки и что ветка не отправлена в удалённый репозиторий.

Больше ничего не делать.
